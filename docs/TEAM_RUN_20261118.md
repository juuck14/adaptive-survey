## 검증

자동 테스트 150개와 제공 검증기를 통과했다. 두 생성환경의 Context별 2명 pilot에서
원래 계산과 캐시 기반 계산의 선택 문항·응답이 같았다. 최대 선택 JS 점수 차이는
MNL 2.32e-12, panel MMNL 1.04e-9 이하였다. 본 실행은 가속 계산을 사용했다.
원본 회차별 표본의 프로필·ID·Context, 9문항의 초기 순서와 중복, Context·층별 인원,
응답은행 값, 출력 32개 열과 실행 완료 기록을 확인했다.

## 최종 평가

현재 산출물은 공통 최종 추정기에 전달할 설문 응답이다. 생성 계수에 대한 Bias·RMSE와
Fixed 대비 효과는 Junyuk의 공통 MNL/panel MMNL 추정 이후 보고한다.
