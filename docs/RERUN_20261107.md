# Fixed efficient / Non-graph 재실험 — 2026-11-07

초기 4문항을 포함한 예산 6·9·12·15·18 설정으로 두 방법을 다시 학습하고 평가했다. MMNL에서 예측 NLL의 전체 예산 평균은 Non-graph가 조금 낮았지만 paired 95% 구간에는 0이 포함됐다. 모집단 MNL의 전체 응답 대비 계수 RMSE는 MMNL의 예산 6·9·12에서 Non-graph가 더 작았다.

## 실행 조건

- 기존 Nemotron 연동 패널의 train 180명, validation 60명, test 300명을 그대로 사용했다. 응답자 분할과 MNL/MMNL 응답값을 유지하고 새 protocol manifest와 checkpoint를 만들었다.
- Core 코드: `fcd4c1c2f0a1978c5b096bcfe389969077a64f49`. 실행기·집계기와 파일별 source SHA-256을 함께 기록했다.
- MMNL 주실험과 MNL 대조실험을 각각 학습 seed 2026·2027·2028, seed당 ensemble 5개로 실행했다. 총 30개 신경망을 새로 학습했다.
- 학습 상한은 120 epochs × 1,024 episodes, batch 64, validation 720 episodes, patience 30이다. Validation NLL로 checkpoint를 선택했다. Acquisition rule은 학습하지 않았다.
- Prediction / preference 두 경로의 무작위 부분 이력을 같은 learner가 학습했다. 평가 중에는 모든 가중치를 고정했다.
- 각 seed에서 Fixed와 Non-graph는 동일한 Choice learner/checkpoint를 사용했다. Fixed 순서는 train MNL Fisher 정보로 응답 공개 전에 설계했다.
- 예산은 응답자 한 명의 Context 하나에 적용한다. 공통 초기 문항은 블록마다 2개, 총 4개다. 세 Context는 별도 이력으로 평가한다.
- Prediction은 후보 14개와 보호된 holdout 4개에서 6·9·12를 평가했다. Preference는 전체 18개 후보에서 6·9·12·15·18을 수집했다. 15·18의 held-out 예측은 계산하지 않았다.
- Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, PyTorch 2.15.0+cpu. 실행 결과의 runtime manifest가 기준이다.

## 이력 사용과 실행 검사

- 여섯 조건의 질문 경로에서 초기 문항·실제 응답의 일치, 질문 중복 방지, 전체 예산 및 공통 reference 일치를 확인했다. 방법·예산·seed·생성 환경을 합쳐 60개 모집단 비교를 완료했다.
- 초기 답변의 영향은 test와 별도로 validation 60명 × 3 Context에서 진단했다. 질문·프로필·후보·RNG를 고정하고 초기 네 답변을 각각 A→B→C→NONE→A로 바꾼 뒤 다섯 번째 질문을 다시 선택했다.

| 생성 환경 | 다섯 번째 질문 변경 비율, seed별 | 빈 이력 NLL | 초기 4응답 NLL |
|---|---|---:|---:|
| MMNL | 37.22% / 42.78% / 37.78% | 1.211064 | 1.125105 |
| MNL | 13.33% / 9.44% / 20.56% | 1.159700 | 1.159647 |

MMNL에서는 초기 응답에 따라 질문 선택이 바뀌고 이력을 넣은 예측이 더 좋았다. MNL에서는 이력에 따른 NLL 변화가 작고 초기 4응답 이후의 최대 Weighted JS 평균도 약 10⁻⁹ 수준이었다. MNL의 질문 변경 비율만으로 유의미한 정보 획득을 주장하지 않는다. 이 표는 checkpoint 선택에 사용된 validation cohort의 동작 진단이며 독립적인 test 성능으로 사용하지 않는다.

- 자동 테스트 145개와 두 생성 환경의 소규모 학습→평가→MNL 분석→집계 smoke 실행이 통과했다.
- 한 response realization과 한 응답자 분할에서의 결과다. 학습 seed 3개는 새로운 응답 생성이나 분할 반복을 대신하지 않는다.
